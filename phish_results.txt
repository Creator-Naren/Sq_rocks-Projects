Scoring rules
-------------
+30  not HTTPS
+20  each phishing keyword in host (login, verify, secure, update, account,
      bank, paypal)
+25  more than 3 dots in host (deep subdomain abuse)
+40  IPv4 address in host
+25  '@' anywhere in URL (user-info trick / URL hiding)
+30  punycode label (xn--) -> homograph attack
+15  suspicious TLD (.zip .mov .top .xyz .tk .click .link)
Score capped at 100.

Notes
-----
- github.com and the google.com search URL correctly score 0%.
- Keyword check looks for substrings in the host, so partial words can add
  points; a real registered-domain parse (tldextract / PSL) would reduce
  false positives.
